claude-statusline is now a single binary. The three per-platform script trees —
Bash for macOS and Linux, PowerShell for Windows — have been replaced by one
Rust implementation that renders identically on all of them.

**This is a release candidate.** It is feature-complete and every rendered state
is verified against the scripts it replaces. If you would rather wait for the
stable release, the normal install command continues to ignore prereleases.

## Why

Three copies of one status line meant every change was written three times, and
the Bash-to-PowerShell axis was a rewrite in a second language each time. The
scripts also needed `jq`, Bash 4+, or PowerShell 5.1+ on your machine, and paid
a ~124 ms interpreter startup on every refresh — which is what the caching
layers existed to hide.

## What changes for you

**Nothing you can see.** Rendered output is byte-identical to the scripts across
18 captured states — git states, payload edge cases, transcript sizes, subagent
feed tiers — replayed on all six published targets on every build.

**No runtime dependencies.** No `jq`, no Bash version floor, no PowerShell
version floor. Linux builds are statically linked against musl, so one artifact
runs anywhere including Alpine and older glibc.

**It is faster.** End-to-end medians, one fresh process per probe, script against
binary on the same host:

| | Windows | macOS | Linux |
|---|---|---|---|
| Typical refresh | 311.8 → 22.1 ms | 70.5 → 5.0 ms | 13.2 → 1.3 ms |
| After the transcript grows | 1527.1 → 72.4 ms | 1282.0 → 74.4 ms | 299.8 → 62.1 ms |

Windows numbers are from a maintainer machine; macOS and Linux from hosted
runners. The Windows binary now finishes a refresh in less time than
`powershell.exe` used to take to start.

## Breaking

**The install URLs moved to `install/`.** The old per-OS paths are gone:

```
master/macos/install.sh    ->  master/install/install.sh
master/linux/install.sh    ->  master/install/install.sh
master/windows/install.ps1 ->  master/install/install.ps1
```

If you have the old command saved anywhere, update it. A stale URL fails
silently — `curl -fsSL` prints nothing on a 404 and `bash` exits 0 — so it will
look like the installer ran and did nothing.

## Upgrading from the scripts

Run the installer. It detects a script installation, and only after the new
binary passes a self-check does it remove the old scripts and repoint
`settings.json`. Your `notify-config.json` is left alone, and notifications stay
enabled if they already were.

If the self-check fails, nothing is touched: the previous installation is
restored and `settings.json` is left as it was.

## Installing this candidate

```bash
curl -fsSL https://raw.githubusercontent.com/axlaser/claude-statusline/master/install/install.sh | bash -s -- --pre
```

```powershell
& ([scriptblock]::Create((irm https://raw.githubusercontent.com/axlaser/claude-statusline/master/install/install.ps1))) --pre
```

`--pre` opts into prereleases. Without it you stay on the latest stable release.
To return to stable later, re-run the install command without the flag.

## Verifying the download

The installer verifies the SHA-256 before placing anything, and there is no path
that skips it. To check by hand:

```bash
sha256sum --check --ignore-missing checksums.txt
```

Every artifact also carries a build-provenance attestation traceable to the
commit and workflow that produced it. The installer verifies it automatically
when the [GitHub CLI](https://cli.github.com) is present, and `--require-attestation`
makes a missing verifier a failure rather than a warning:

```bash
gh attestation verify claude-statusline-<target> \
  --repo axlaser/claude-statusline \
  --signer-workflow axlaser/claude-statusline/.github/workflows/release.yml
```

## Reporting a problem

The status line is built to fail silently — it never writes to stderr and always
exits 0, because anything else breaks Claude Code's UI. That means a fault
reaches you as an absent status line with no error. Two things help:

```bash
~/.claude/bin/claude-statusline self-check   # exits 0 if the renderer is sound
STATUSLINE_DEBUG=1                           # then read ~/.claude/statusline-debug.log
```

A `panic caught in subcommand` line in that log is always a bug worth reporting.
